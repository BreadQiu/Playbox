# Blocky 24 v0.3.0 — 精准拖拽与非负提示

本次版本将网页品牌统一为 Blocky 24，并修正手机与桌面上的拖拽目标错位、运算符误选和负数开头提示。

## 在线游玩

- Blocky 24: https://BreadQiu.github.io/Playbox/
- 游戏页面: https://BreadQiu.github.io/Playbox/blocky-24/

## 改动

- 浏览器标题、页面品牌、社交分享标题和页脚统一显示为 Blocky 24。
- 幽灵卡优先按实际重叠面积选择目标数字牌和运算符。
- 运算符命中框固定为手机 `48×48px`、桌面和平板 `56×56px`，可见圆泡单独放大。
- 拖拽期间只有真正参与计算的运算符会高亮，鼠标悬浮不会产生第二个误导目标。
- 提示优先返回结果非负的第一步；例如 `[1,1,3,13]` 提示为 `3 − 1`。
- README 删除本地运行、测试、项目结构和发布板块。
