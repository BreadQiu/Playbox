# Playbox v0.1.0 — Blocky 24

Playbox 的第一个公开版本，包含游戏目录和第一款游戏 Blocky 24。

## 在线游玩

- Playbox: https://BreadQiu.github.io/Playbox/
- Blocky 24: https://BreadQiu.github.io/Playbox/blocky-24/

## Blocky 24

- 使用拖拽把两张数字牌通过加、减、乘、除合并成一牌。
- 支持鼠标、触控和触控笔，桌面、手机与平板共用固定 2×2 布局。
- 随机题目支持 `1–9` 和 `1–13`，可配置是否允许无解题。
- 使用精确分数计算和完整成对合并求解器。
- 包含正计时、撤销、重来、提示、有解检查和无解后的下一题流程。
- 提供“积木实体”和“喜剧卡通”两种程序化音效，并支持静音。
