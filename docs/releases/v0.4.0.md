# Blocky 24 v0.4.0 — 新手引导与多彩牌面

本次版本加入动画新手提示、上一题解法和更鲜明的卡牌配色，并进一步精简游戏界面。

## 在线游玩

- Blocky 24: https://BreadQiu.github.io/Playbox/
- 游戏页面: https://BreadQiu.github.io/Playbox/blocky-24/

## 新增

- 进入游戏自动打开动画新手提示，演示拖拽合并、灯泡提示、撤销和蓝色“无解”检查。
- 新手提示中的无解动画会从蓝色“无解”切换为绿色“此题无解”。
- 撤销按钮右侧显示本次访问中的上一题完整解法；无解题显示原始数字和“无解”。
- 成功组成 24 后，最终牌内会显示可点击的“下一题”。

## 改进

- 新手提示打开期间计时继续运行。
- 普通卡牌使用 8 色高饱和纯色池，普通牌、初始牌和合并新牌都保证同屏颜色不重复。
- 成功 24 使用鲜绿色 `#24D97D`，失败结果使用鲜红色 `#FF3B5C`。
- 删除卡面内部装饰圆框和偏下侧计算式。
- 上一题算式使用精确求解结果并保留必要括号。
- 浏览器页面名称保持为单独的 `Blocky 24`。
