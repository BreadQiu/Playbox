# Playbox v0.2.0 — 默认喜剧卡通音效

本次版本统一 Blocky 24 正式入口与“喜剧卡通”试听入口的音色选择，让从 Playbox 首页和直接游戏地址进入时获得相同的拖动声音。

## 在线游玩

- Playbox: https://BreadQiu.github.io/Playbox/
- Blocky 24: https://BreadQiu.github.io/Playbox/blocky-24/

## 改动

- Blocky 24 默认加载“喜剧卡通”程序化音效。
- 从 Playbox 首页、README 直链或游戏正式地址直接进入时，开始拖动卡牌不再回退到“积木实体”音效。
- 继续支持 `?sound=tactile`，用于显式试听“积木实体”音色。
- 继续支持 `?sound=comedy`，用于显式选择默认音色。
- 静音状态仍会持久保存，不改变游戏操作、计时、提示或解题规则。
- Playbox 首页、README 和工作区包版本统一更新为 `v0.2.0`。
