# 24 Point Yellow Tile Game Implementation Plan

**Goal:** Build a static, single-player 24-point game with pointer drag-to-merge controls and a yellow cartoon tile aesthetic.

**Architecture:** Pure TypeScript modules own exact arithmetic, puzzle generation, game state, timer, and settings. A native DOM/CSS presentation layer owns rendering and Pointer Events.

**Tech Stack:** Vite, TypeScript, Vitest, Playwright, `@fontsource-variable/fredoka`, native DOM and CSS.

**Spec:** `docs/superpowers/specs/2026-11-16-24-game-design.md`

## Global Constraints

- First screen is immediately playable.
- Mouse, touch, and pen use the same drag-to-operator interaction. No keyboard-only merge flow is required in v1.
- Source card uses `source op target`; source slot empties and target slot receives the exact rational result.
- Digits allow repetition and are independently selected from `1-9` or `1-13`.
- When unsolvable puzzles are disabled, only solvable puzzles are generated.
- Timer counts up: new puzzle resets to zero; retry and undoing a loss continue accumulated time; hidden tab pauses.
- No audio, backend, account, multiplayer, leaderboard, or network dependency in v1.
- Use visual direction A: yellow block toy, cream/coral/mint tiles, ink outlines, hard offset shadows.
- GitHub Pages build uses relative asset URLs.
